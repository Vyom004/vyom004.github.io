## Deploying

Hosted with GitHub Pages. In the repo: **Settings → Pages → Source: Deploy from a branch →
`main` / `(root)`**. Live within a minute or two.

## Editing

Everything lives in `index.html`. The colour palette and dark-mode variants are CSS custom
properties in the `:root` blocks at the top of the `<style>` section — change a value once there
and it updates everywhere.

To swap the portfolio links, search for `href="https://drive.google.com` and replace each with the
public video or gallery URL.
