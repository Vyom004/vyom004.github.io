- **AAA game-style animation** — trailers, promos, title sequences, stylised brand worlds

- **Original music** — songs and scores in Hindi and English, written to the cut
- **Voice, sound & final post** — voice direction, sound design, grade, delivery in every ratio

Roughly 48 hours from brief to three visual directions, about a week to a finished 30-second film.

## About this repo

The portfolio site itself — a single self-contained `index.html`, no build step and no
dependencies. Published with GitHub Pages at https://vyom004.github.io

Fonts load from Google Fonts; everything else is inline. The colour palette and dark-mode
variants are CSS custom properties in the `:root` blocks at the top of the `<style>` section.

Work links point at folders rather than individual files, so new work added to a folder
appears on the site with no code change.
